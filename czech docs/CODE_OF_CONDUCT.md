Model Unbreak má být technicky náročný, ale zároveň přívětivý open-source projekt. Kritika kódu, benchmarků, architektury a předpokladů je vítaná; útoky na lidi ne.

## Náš standard

Očekávané chování zahrnuje:

- technické neshody řešit důkazy a s respektem,
- dávat actionable review feedback,
- oddělovat identitu člověka od kvality návrhu,
- přiznávat nejistotu a opravovat chyby,
- respektovat soukromí a confidential security reports,
- vyhýbat se harassmentu, výhrůžkám, diskriminaci a záměrnému ponižování.

Nepřijatelné chování zahrnuje:

- personal attacks nebo sustained hostility,
- discriminatory nebo sexual harassment,
- zveřejňování private information bez svolení,
- záměrnou sabotáž project infrastructure nebo discussions,
- nátlak na contributory, aby zveřejňovali private benchmarks, credentials, model data nebo osobní informace.

## Technická neshoda

Silný nesouhlas je povolen. Preferuj tento postup:

1. popiš pozorovaný problém,
2. přilož reprodukci nebo data,
3. vysvětli trade-off,
4. navrhni alternativu,
5. udržuj diskusi u samotné práce.

## Rozsah

Kodex platí pro repository issues, pull requests, discussions, reviews, project-maintained chat spaces a další prostory, kde někdo zastupuje projekt.

## Vymáhání

Maintainer může upravit, skrýt, zamknout nebo odstranit obsah porušující tento standard a při opakovaném nebo závažném porušení omezit participation.

Good-faith technické chyby, failed experiments a unpopular architecture proposals nejsou conduct violations.
