# Code of Conduct

[![Scope](https://img.shields.io/badge/scope-repository%20%26%20project%20spaces-2563eb)](#scope)
[![Enforcement](https://img.shields.io/badge/enforcement-maintainer--led-6f42c1)](#enforcement)

Model Unbreak is intended to be a technically demanding but welcoming open-source project. Criticism of code, benchmarks, architecture, and assumptions is encouraged; attacks on people are not.

## Our standard

Expected behavior includes:

- discussing technical disagreements with evidence and respect,
- giving actionable review feedback,
- separating a person's identity from the quality of a proposal,
- acknowledging uncertainty and correcting mistakes,
- respecting privacy and confidential security reports,
- avoiding harassment, threats, discrimination, or deliberate humiliation.

Unacceptable behavior includes:

- personal attacks or sustained hostility,
- discriminatory or sexual harassment,
- publishing private information without permission,
- intentionally sabotaging project infrastructure or discussions,
- pressuring contributors to reveal private benchmarks, credentials, model data, or personal information.

## Technical disagreement

Strong disagreement is allowed. Prefer this pattern:

1. state the observed problem,
2. provide reproduction or data,
3. explain the trade-off,
4. propose an alternative,
5. keep the discussion about the work.

## Scope

This code applies to repository issues, pull requests, discussions, reviews, project-maintained chat spaces, and other spaces where someone is representing the project.

## Enforcement

The maintainer may edit, hide, lock, or remove content that violates this standard and may restrict participation for repeated or severe violations.

Good-faith technical mistakes, failed experiments, and unpopular architecture proposals are not conduct violations.
